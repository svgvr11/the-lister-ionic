# Tarea activa

No hay tarea activa.

Cuando se inicie una tarea, este archivo debe contener:

- **Objetivo**: qué se quiere lograr.
- **Contexto**: por qué se hace, qué problema resuelve.
- **Alcance**: qué está dentro y qué está fuera.
- **Fuera de alcance**: qué explícitamente no se toca.
- **Archivos o módulos relevantes**: rutas a los archivos involucrados.
- **Restricciones**: reglas del Harness que aplican.
- **Criterios de aceptación**: condiciones verificables para dar la tarea por terminada.
- **Pruebas requeridas**: qué specs deben pasar.
- **Estado**: pendiente / en curso / bloqueado / terminado.

Un agente nuevo no debe implementar nada si este archivo está vacío o no existe.
